## 📌 О проекте

Репозиторий объединяет материалы по изучению основ программирования на Python: исходный код заданий, методические документы и презентации. Структура сохраняет группировку по практическим занятиям и темам, чтобы нужный материал было легко найти и запустить.

### Что внутри

- **Практика № 1–9** — задания по темам соответствующих занятий.
- **Задачи на логику** — дополнительные задачи для тренировки алгоритмического мышления.
- **Задания в конце пары** — отдельные упражнения, сгруппированные по датам.
- **Методические материалы** — документы и презентации к занятиям.

## ⚙️ Требования

- macOS, Windows или Linux;
- Python 3;
- терминал или редактор кода (например, Visual Studio Code или PyCharm).

В заданиях используются стандартные возможности Python. Если конкретному файлу нужны дополнительные библиотеки, их необходимость должна быть указана в самом задании.

## 🚀 Быстрый старт

### 1. Установить Python

Проверьте, установлен ли Python:

```bash
python3 --version
```

Если команда не найдена, установите Python 3 с официального сайта: https://www.python.org/downloads/

На Windows обычно используется команда `py` вместо `python3`.

### 2. Скачать репозиторий

```bash
git clone https://github.com/11OP-group/practice-StepanStepurov.git
cd practice-StepanStepurov
```

Если репозиторий уже находится на компьютере, перейдите в его папку через `cd`.

### 3. Найти и запустить задание

Например, чтобы посмотреть файлы практической работы № 9:

```bash
ls "Практика№9"
```

Запустите нужный файл, указав его путь:

```bash
python3 "Практика№9/Задание 1.py"
```

Для другого задания замените путь на имя нужного `.py`-файла. Если в названии есть пробелы или символ `№`, оставляйте путь в кавычках.

### 4. Проверить синтаксис без запуска программы

```bash
python3 -m py_compile "Практика№9/Задание 1.py"
```

Команда проверяет синтаксис указанного файла. Она не заменяет проверку правильности результата.

## 🧭 Как пользоваться материалами

1. Откройте папку нужного практического занятия.
2. Прочитайте условие в соответствующем документе, если он есть.
3. Откройте файл задания `.py`.
4. Запустите программу через терминал или IDE.
5. Проверьте результат на нескольких входных значениях.

## 🛠️ Рекомендации по запуску

- Выполняйте команды из корневой папки репозитория.
- Используйте кавычки вокруг путей с пробелами и специальными символами.
- Для запуска отдельного файла не требуется собирать весь репозиторий.
- Если программа не запускается, сначала проверьте версию Python и путь к файлу.

## 📦 Зависимости

Отдельный файл `requirements.txt` в предоставленном наборе материалов не обнаружен. Большинство базовых учебных задач Python не требуют установки сторонних пакетов. Не устанавливайте дополнительные библиотеки без необходимости.
