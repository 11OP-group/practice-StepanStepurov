## 🐍 Python — практические задания

Папка: `Практические задания для Ефимовой А.Н`

Задания сгруппированы по занятиям и темам: у каждой работы своя папка с кодом и сопутствующими материалами.

| Раздел | Описание |
|:--|:--|
| **Практика № 1–9** | Последовательные практические работы по темам занятий |
| **Задачи на логику (13.10.26)** | Дополнительные задачи для тренировки алгоритмического мышления |
| **Задания в конце пары** | Короткие упражнения, сгруппированные по датам |
| **Методические материалы** | Документы и презентации к занятиям |

### 🗓️ Задания в конце пары

| Дата | Тема | Задачи |
|:--:|:--|:--|
| **05.10.26** | Ветвления. Условный оператор `if / elif / else` | 5 задач: проверка года, тип треугольника, количество дней в месяце, весовая категория, смешивание цветов |
| **19.10.26** | Арифметический цикл `for` | 4 задачи: чётные числа, факториал, вывод диапазона `m…n` в любом направлении, отбор чисел по условиям делимости |

### 🔑 Освоенные темы

| Тема | Конструкции |
|:--|:--|
| Ввод и вывод | `input()`, `print()`, f-строки |
| Ветвления | `if`, `elif`, `else`, составные условия `and` / `or` |
| Циклы | `for`, `range()` с шагом, обратный порядок |
| Арифметика | `%`, `*`, накопление результата в цикле |

## 🚀 Быстрый старт

Убедитесь, что установлен [Git](https://git-scm.com/), затем выполните:

```bash
git clone https://github.com/11OP-group/practice-StepanStepurov.git
cd practice-StepanStepurov
```

### ⚙️ Требования

| Инструмент | Версия | Для чего |
|:--|:--|:--|
| Python | 3.x | Запуск заданий на Python |
| .NET SDK | актуальная LTS | Сборка и запуск проектов на C# |
| Редактор кода | любой | Например, VS Code, PyCharm, Visual Studio, Rider |

Поддерживаются **Windows**, **macOS** и **Linux**.

## ▶️ Запуск проектов

### 🐍 Python

```bash
cd "Практические задания для Ефимовой А.Н/Задание в конце пары(19.10.26)"
python "Задание 1.py"
```

> На macOS и Linux используйте `python3` вместо `python`.

### ⚙️ C#

```bash
cd "Практические задания для Матысик И.A/project_final"
dotnet run
```

Подробные инструкции по каждому проекту находятся в README внутри соответствующих папок.
