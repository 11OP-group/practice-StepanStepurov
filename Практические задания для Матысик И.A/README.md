## 📖 О проекте

В каталоге собраны три консольных проекта на C#:

1. **Банковская задача** — расчёт начислений по вкладу с ежемесячной капитализацией.
2. **Гладиатор через классы** — вариант задачи, организованный с использованием классов.
3. **Гладиатор** — вариант симуляции боя с отдельной моделью нанесения урона.

Проекты используют общую библиотеку `Labs.Common` для вспомогательных компонентов терминального ввода, журналирования, пауз и генерации случайных значений. В каталогах также сохранены схемы `.drawio`.

## ✨ Основные особенности

- отдельный проект для каждой задачи;
- повторно используемая библиотека `Labs.Common`;
- разделение логики, ввода и консольного представления;
- обработка отдельных ошибок ввода;
- схемы алгоритмов в формате Draw.io;
- единые настройки сборки через `Directory.Build.props`.

## ⚙️ Требования

- .NET SDK, совместимый с целевой платформой проекта;
- macOS, Windows или Linux;
- терминал или IDE с поддержкой C#.

Целевая платформа задаётся в `Directory.Build.props`. Перед запуском проверьте её значение и установленные SDK.

Проверить установку .NET:

```bash
dotnet --info
dotnet --list-sdks
```

Если `dotnet` не найден, установите .NET SDK с официального сайта: https://dotnet.microsoft.com/download

## 🚀 Быстрый старт

### 1. Перейти в каталог проекта

Если репозиторий уже клонирован, перейдите в корень репозитория, затем в папку `project_final`. Если этот README находится непосредственно в корне проекта, этот шаг пропустите.

```bash
cd "project_final"
```

### 2. Запустить банковскую задачу

```bash
dotnet restore "Банковская задача/Labs.TermDeposit/Labs.TermDeposit.csproj"
dotnet run --project "Банковская задача/Labs.TermDeposit/Labs.TermDeposit.csproj"
```

### 3. Запустить проект «Гладиатор через классы»

```bash
dotnet restore "Гладиатор через классы/Labs.Arena/Labs.Arena.csproj"
dotnet run --project "Гладиатор через классы/Labs.Arena/Labs.Arena.csproj"
```

### 4. Запустить проект «Гладиатор»

```bash
dotnet restore "Гладиатор/Labs.ArmorStrike/Labs.ArmorStrike.csproj"
dotnet run --project "Гладиатор/Labs.ArmorStrike/Labs.ArmorStrike.csproj"
```

Команды следует выполнять из каталога `project_final`. Если вы находитесь внутри папки отдельной задачи, используйте относительный путь к `.csproj` из текущего расположения.

## 🧪 Сборка

Чтобы проверить отдельный проект без запуска:

```bash
dotnet build "Банковская задача/Labs.TermDeposit/Labs.TermDeposit.csproj"
dotnet build "Гладиатор через классы/Labs.Arena/Labs.Arena.csproj"
dotnet build "Гладиатор/Labs.ArmorStrike/Labs.ArmorStrike.csproj"
```

## 🧠 Архитектура

### `Labs.TermDeposit`

Консольное приложение для расчёта начислений по вкладу. Код разделён на доменные модели, сбор входных данных, механизм начисления, каталог ставок и консольное представление.

### `Labs.Arena`

Вариант симуляции боя, организованный через классы и отдельные компоненты предметной области: участники, модель урона, ввод характеристик и движок дуэли.

### `Labs.ArmorStrike`

Отдельное консольное приложение для задачи «Гладиатор», использующее собственную модель расчёта удара и общие вспомогательные компоненты.

### `Labs.Common`

Общие интерфейсы и реализации для журналирования событий, взаимодействия с терминалом, задержек и источника случайных значений.

## 🔎 Примечания

- Формат ввода дробных чисел может зависеть от региональных настроек системы.
- Если сборка сообщает, что целевой .NET SDK отсутствует, проверьте `Directory.Build.props` и установленные SDK.
- Журналы приложения, если включены конкретной реализацией, создаются во время выполнения; не добавляйте генерируемые файлы в репозиторий без необходимости.
- В предоставленном наборе не обнаружены отдельные автоматизированные тестовые проекты, поэтому успешная сборка сама по себе не доказывает корректность всех сценариев.
